# PixelPay

PixelPay adalah konsep website gaming top-up store bertema **lime dark** yang dibuat sebagai project portfolio front-end. Project ini menghadirkan alur simulasi lengkap dari memilih game hingga memantau status transaksi.

> Project portfolio — tidak memproses uang, akun game, atau diamond sungguhan.

## Fitur utama

- Katalog dan pencarian game
- Halaman top up khusus untuk setiap game
- Validasi User ID dan Server
- Pilihan nominal, jumlah, dan metode pembayaran
- Simulasi pembayaran dengan loading state
- Status dan riwayat transaksi
- Login serta profil demo
- FAQ interaktif dan halaman case study
- Responsive untuk desktop, tablet, dan mobile

## Tech stack

React · TypeScript · Vinext · CSS · Lucide Icons · Local Storage · OpenAI Sites
